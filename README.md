# Simon Says Game 🎮

A simple and fun web-based "Simon Says" memory game built with HTML, CSS, and JavaScript.

## 🚀 Demo

You can play the game live here (add link if deployed)  
Or download and run it locally!

## 🛠️ Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript

## 📁 Features

- Interactive and colorful buttons
- Increasing difficulty with each level
- Keeps track of current level and high score
- Audio feedback on button press
- Game Over animation
